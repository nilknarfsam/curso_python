# 🔰 Módulo 01: Fundamentos de Python

Bem-vindo ao módulo de **Fundamentos da Linguagem Python**. Aqui você aprenderá a base sólida necessária para dominar a sintaxe, os tipos de dados primitivos, as estruturas lógicas de decisão e os loops de repetição.

---

## 🎯 Objetivos de Aprendizagem

- Compreender a tipagem dinâmica e forte do Python.
- Dominar os tipos primitivos fundamentais: `str` (texto), `int` (inteiro), `float` (ponto flutuante) e `bool` (booleano).
- Manipular entradas e saídas de dados no terminal (`print` e `input`).
- Aplicar estruturas lógicas de tomada de decisão (`if`, `elif`, `else`) com operadores relacionais e lógicos.
- Dominar estruturas de repetição (`while` e `for`) para automação de tarefas iterativas.
- Conhecer as primeiras estruturas de coleções: Listas (`list`) e Tuplas (`tuple`).

---
